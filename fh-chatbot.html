FH Aachen Chatbot

University team project · Frontend engineering

Oct 2025 – Feb 2026

A clearer way to learn with AI.

An AI tutor for students at FH Aachen. I worked on the frontend: breaking up the chat interface, connecting authenticated APIs, and making responses stream into the conversation.

Explore the case study
Context10-person university team
ScopeFrontend architecture · API integration · Chat UX
Built withVue.js · JavaScript · Laravel · REST APIs

Help within the course.

The chatbot helps students ask questions about their coursework. It uses selected course documents and retrieves relevant material as context for an AI-generated answer. The interface needs to make that conversation easy to follow, including the time spent waiting for a response.

From question to answer.

Explore how the conversation works. My contribution focused on the frontend around this flow.

  1. Choose context
  2. Send a question
  3. Stream the answer
  4. Continue learning

Selected documents + student question

Start with the course.

Students choose the documents relevant to their question. The selected document IDs travel with the message, keeping the conversation tied to the intended material.

Vue composable → Laravel API

Connect the conversation.

The frontend creates a conversation and sends the message through the authenticated API. Reusable chat actions keep request handling separate from the visual components.

Response stream → incremental message updates

Read as the answer arrives.

The application retrieves course context and generates a response. On the frontend, incoming chunks update the answer progressively, so students can start reading while generation continues.

Loading → streaming → complete or error

Keep the state understandable.

Loading indicators, request state, and error handling support the conversation from sending to completion. The student can follow up in the same chat.

My part of the build.

Break up the monolith

Refactored the monolithic chat component into reusable modules, giving the interface clearer responsibilities and making changes easier to isolate.

Separate logic from UI

Developed Vue composables for business logic and API communication, so chat components could focus on the experience instead of managing every request themselves.

Make the wait readable

Integrated authenticated REST APIs and improved token streaming, loading states, and status feedback within the existing team project.

A focused frontend boundary.

The wider application includes a Laravel backend, course-document retrieval, and language-model integration. My case study focuses on the Vue frontend and its API boundary. The retrieval system is part of the team application, rather than a system I claim to have built alone.

An existing product, improved.

This was a collaborative university project. My work demonstrates how I approach an existing codebase: clarify component boundaries, reuse logic, and improve a visible interaction without rebuilding the whole system.
